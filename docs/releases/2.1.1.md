# Android 2.1.1：区分额度错误和待回答问题

修复 Android 将 Codex 额度错误显示成“待你回应”的问题。额度耗尽、请求限流和普通运行错误分别说明原因，并保留本地 Agent 返回的原始错误；没有回应动作的错误不会显示成选择题。执行中的回应显示“正在处理”。

真正需要回答的问题优先展示，避免旧的错误卡片遮住问卷。手机可选择单选、多选或填写自定义回答，再提交给本地 Agent。未开启接管、设备离线或暂不支持的问题格式，会说明无法提交的原因；未知格式不会提交不完整的问卷。大字号下提交按钮随文字高度扩展，避免文字被裁切。

本次只更新 Android，版本 2.1.1（versionCode 13）。沿用现有 Runtime notice 和回应接口，不需要部署 Server 或更新 Connector；Web、Desktop、iOS 本次没有同步调整错误提示。保留 2.1.0 的共享工作区、设备筛选、消息时间和此前公式修复。

## 验证方式与边界

新增分类和展示优先级单元测试。模拟器用与 Codex 实际协议相同的错误、问卷结构运行正式界面组件；点击选项、输入自定义回答并通过正式 Controller/API 发出请求，在设备本地测试服务器核对路径、动作和答案。覆盖额度提示、单选替换、多选、自定义回答、长问题及两倍字号、未接管、离线和未知格式。另运行已有公式显示、滚动和前台服务检查。

额度错误使用隔离的协议样例；没有消耗真实 Codex 额度来重现耗尽，也没有代用户批准或回答生产会话中的问题。Android 模拟器验证不能代表所有品牌真机。

本次构建实际通过：27 项 JVM 单元测试、13 项 Android 15 / API 35 模拟器检查，以及旧路由检查。已验证同签名覆盖安装。

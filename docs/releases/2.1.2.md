# Android 2.1.2：服务器发布 App 更新

自托管管理员可在服务器发布同签名 APK，手机打开 App、回到前台或停留前台每 5 分钟会检查新版，也可在设置里手动检查。用户点击更新后显示下载进度，下载完整并通过校验后，交给安卓系统确认覆盖安装。忽略当前构建后不会重复弹出，更高版本仍会提示。

Android 更新清单与 Server 的健康检查版本分开，发布 Android 不需为了触发提示而改 Server 版本。下载后验证字节数、SHA-256、应用包名、版本和已安装 App 的签名；文件损坏、截断或签名不匹配时不会进入安装流程。

本次仅更新 Android 至 2.1.2（versionCode 14），新增部署层静态发布目录，不改数据库和 `/api/v2`，其他客户端不受影响。保留此前公式、共享工作区、设备筛选、消息时间和 Codex 错误提示修复。更新部署见 [说明](../../deploy/ANDROID-UPDATES.md)，清单格式见 [契约](../api/android-updates.md)。

旧版 APK 的更新下载地址仍是占位地址，无法由服务器补上客户端能力；需要先手动安装一次 2.1.2。此功能是在 App 前台提示，不是在后台发送系统推送，也不会绕过安卓的安装确认。

验证：31 项单元测试及旧路由检查通过。在 Android 15 隔离模拟器上用包含新更新器的较低构建，实际从自托管公网读取清单并下载正式 2.1.2，验证忽略、重新检查、完整性和签名；正式安装器打开系统确认页，确认后实际覆盖升级至 versionCode 14，原有 App 自有验证记录保留。模拟器预先允许安装来源，首次权限授权仍需用户在自己的手机上确认。

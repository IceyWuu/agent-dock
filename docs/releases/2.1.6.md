# Android 2.1.6 — 文件工作台

- 按设备、项目查看文件，筛选 Markdown、PDF、图片与其他类型。
- Markdown 排版阅读／源码切换，PDF 翻页与缩放，图片预览；恢复 Markdown 滚动位置和 PDF 页码。
- 对话和文件可单独全屏，也可分屏：手机竖屏上下排列，横屏左右排列，支持拖动调整比例。
- 聊天中的交付文件卡片、文件链接与支持的附件使用统一阅读器。
- 工作设备桥接 2.1.1 及 bundled Connector 2.1.1 同步 DSH `present` 文件引用（投影版本 4）；需重启 DSH，旧检查点自动重新校准。原生图片块／自定义 UI 尚未完整同步。
- 沿用既有签名与服务器 Android 更新通道，无 Server 或数据库变更。桌面端和 iOS 布局未改。

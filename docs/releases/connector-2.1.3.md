# Connector 2.1.3 — 在手机回答 Codex 电脑端问题

- 同步原 Codex 电脑端的待处理审批、暂停问答，以及允许稍后回答的异步问题。选项和自定义文字使用手机已有的问答界面。
- 答案发回原电脑端持有的对话；电脑先回答、问题变化或失效时同步关闭旧卡片。拒绝重复提交，失败后保留重试入口。
- 继续使用既有 Server／客户端接口，无数据库或手机正式代码变化。Android 2.1.7 无需重新安装。其他电脑需要安装 Connector 2.1.3，配置步骤见 [手机同步](../setup/codex-mobile-sync.md)。

验证：385 项 Codex 相关检查通过；Android 44 项单元检查、构建和旧路由检查通过；API 35 模拟器 11 项交互检查通过，新增的 3 项选项／自定义答案／异步问答检查单独复跑通过。模拟器通过隔离的桌面 IPC 测试端验证完整提交链路，未操作真实模型任务，也未验证其他手机真机。已核对本机安装的 Codex 问答数据格式和转发方法。

全量 Connector 静态检查存在本轮修改以外的既有问题；修改文件的静态检查通过。

# 2.1.0：共享工作区和消息时间

自托管服务可启用免账号共享工作区。两人共用现有设备、项目、聊天和附件。Android 首页可按设备筛选，并在本机记住选择。Android、Web、Desktop、iOS 的消息行接入已有创建时间，小字显示发送和接收日期、时间，不随流式更新改变。

## 升级和数据

新增 `/auth/config.sharedWorkspaceEnabled` 和 `POST /auth/shared-session`，各端版本号统一到 2.1.0。Runtime、Connector 协议保持兼容。Android 直接连接共享工作区需要 2.1.0；Web 和桌面 2.1.0 自动进入共享账号，原生端也可经新版 Web OAuth 页完成。旧客户端保存的个人会话可能需要断开重连。

更新 Server/Web 后，在 `deploy/.env` 里设置 `AGENT_SERVER_SHARED_WORKSPACE=true` 并重启服务。默认关闭，其他部署继续使用原账号登录。启用前备份。首次启动会汇集旧账号的设备、项目和会话分享；会话 ID、消息时间、附件和设备凭据保留，重名项目加序号。关闭开关不会自动还原数据归属。能够访问此地址的人可以使用共享工作区的设备、文件和终端，入口应只向使用者开放。

Android 保留 2.0.5 的公式修复，并修复快速进入或退出会话、切换系统显示设置时前台服务启动和停止竞争导致的闪退。共享会话续期不再重置当前聊天或已经加载的列表。

详见 [接口和兼容范围](../api/shared-workspace.md) 和 [部署说明](../../deploy/README.md)。

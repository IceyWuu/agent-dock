# Android 2.1.5：更新安装结果与缓存清理

App 内下载的更新包在复制到 Android 安装会话并提交后自动删除，不再每次保留几十 MB 的原始 APK。安装失败或取消后系统释放其会话副本，复制或提交异常时 App 主动放弃未完成会话；启动时清理旧版遗留的私有更新 APK。安装授权未通过、会话切换和准备失败也会清理待安装的私有文件。

清理仅限 App 私有的 `cache/app-updates`。聊天附件、应用配置和用户保存在微信、浏览器或 Downloads 中的文件不受影响；外部自行下载的 APK 仍需用户自行清理。

更新校验把不同签名、版本过旧和包信息不符分别提示；系统返回的应用冲突、空间不足、安装受限、设备不兼容、无效包、取消和其他失败也有单独文案，不再都显示为下载失败。失败回调会暂存，下次打开 App 即使更新清单尚未加载也能查看原因。无法打开系统安装授权页或确认页时显示权限提示，不直接崩溃。

Android 更新为 2.1.5（versionCode 17）。包名、签名保持与之前分发版本一致，包含 arm64-v8a、armeabi-v7a、x86 和 x86_64 原生库，最低 Android 8.0。覆盖更新和 APK 文件名无关；系统签名检查、其他用户或工作空间中的冲突、厂商安全策略不能由 App 绕过，不应默认建议卸载旧版。

验证使用 Android 15 / API 35 arm64 模拟器：

- 40 项 JVM 测试及旧路由检查通过。
- 覆盖私有缓存清理范围、失败结果持久化、安装复制失败后的会话释放。
- 实际提交安装会话、删除源文件后显示系统确认、取消后确认回调及会话释放。
- 使用不同签名的真实 APK 验证下载校验拦截，以及 Android 安装器真实返回冲突；已安装版本保留。
- 校验非更新版本的拒绝，以及无更新清单时仍显示并可关闭持久化的冲突提示；检查界面截图。
- 实际覆盖 2.1.4 → 2.1.5，确认测试数据保留、旧更新缓存清理、其他缓存文件保留；另通过系统确认接受安装会话验证安装成功。

尚未在各品牌真机、其他 Android 版本或工作空间环境逐一验证，不能据模拟器结果保证所有厂商安装器行为相同。Server、数据库及其他客户端本次不变。

已发布到现有 Android 更新清单。使用正式 2.1.4 在模拟器上验证公网发现更新、忽略后手动检查、完整 HTTPS 下载、长度/SHA-256/包名/版本/签名校验，并经系统确认实际升级至 2.1.5 / versionCode 17。升级后私有更新缓存为空，测试数据和其他缓存文件保留。公网检查首次受模拟器 DNS 故障阻挡，恢复网络后重跑通过。

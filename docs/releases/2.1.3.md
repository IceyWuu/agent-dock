# Android 2.1.3：散聊统一放入“未分组”

首页项目视图将 Codex 散聊自动生成的工作目录、通用用户目录，以及没有可识别项目的对话合并到一个“未分组”文件夹。文件夹可以展开、收起并记住状态，不再为每个临时目录显示一个项目名。设备、Agent、活动/归档筛选继续生效，置顶对话仍在置顶区域。

正常工作项目、手动创建的项目、用户自己改名或置顶的项目继续单独显示。“未分组”只组织客户端列表，不创建虚拟服务器项目，也不修改会话的原项目 ID、工作目录、内容或归档状态；打开散聊仍进入原会话。

Android 版本为 2.1.3（versionCode 15），接口和服务器版本保持兼容，其他客户端本次没有调整项目分组方式。通过 2.1.2 接入的更新清单发布，新版由 App 在前台检查并提示下载安装。

验证：35 项单元测试和旧路由检查通过。Android 15 模拟器实际检查中文“未分组”文件夹、散聊展开、点击进入原会话的回调、两个设备切换、无项目会话、置顶及归档排除、深色主题和两倍字号。已有对话与服务端项目不作数据迁移。

发布后用此前正式 2.1.2 APK 在模拟器检查公网更新，实际提示并下载 2.1.3，文件及签名校验通过；通过系统确认完成覆盖升级到 versionCode 15。上述两项更新链路检查均通过。
